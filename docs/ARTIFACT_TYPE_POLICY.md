# سياسة أنواع العناصر الأمنية

## 1. القرار المعياري

القيم الوحيدة المعتمدة لحقل `security_artifacts.type` هي أنواع USACM v2.2.1 الاثنين والعشرين. لا تُنشأ أكواد جديدة للمسميات العملية مثل «حوكمة»، «مراقبة»، «مراجعة»، «اختبار»، «توعية»، أو «إجراء تصحيحي»؛ لأن هذه المسميات تصف أحيانًا نشاطًا أو سياقًا يندرج تحت أكثر من نوع.

هذه السياسة تفسر اختيار النوع ولا تستبدل USACM. عند التعارض، يفوز USACM v2.2.1.

القاعدة الأساسية:

> صنّف العنصر حسب ماهيته الذاتية، لا حسب الموضوع الذي يتحدث عنه ولا حسب اسم القسم الذي ورد فيه.

## 2. الأنواع المعتمدة وحدودها

| الكود | الاسم | استخدمه عندما يكون العنصر | لا تستخدمه عندما يكون النص |
|---|---|---|---|
| `ART-REQ` | متطلب | نتيجة أو التزامًا واجب التحقيق، دون فرض وسيلة واحدة | آلية تحقيق أو إعدادًا تقنيًا |
| `ART-OBJ` | هدف أمني | نتيجة أمنية عليا مقصودة | التزامًا تفصيليًا أو ضابطًا |
| `ART-PRI` | مبدأ أمني | قاعدة فكرية ثابتة توجه القرارات | سياسة قابلة للاعتماد أو خطوات تنفيذ |
| `ART-POL` | سياسة أمنية | توجيهًا إداريًا معتمدًا يحدد قواعد ومسؤوليات | قيمة تقنية تفصيلية أو دليلًا |
| `ART-STD` | معيار أمني | حدًا أدنى موحدًا وقابلاً للقياس عبر نطاق | إعداد مكوّن منفرد أو خطوات تشغيل |
| `ART-CTR` | ضابط أمني | وسيلة أو ممارسة تقلل خطرًا أو تحقق التزامًا | النتيجة المطلوبة فقط أو سجل التنفيذ |
| `ART-CTE` | تحسين ضابط | إضافة محددة تقوي أو تخصص ضابطًا قائمًا | ضابطًا مستقلًا أو نتيجة اختبار |
| `ART-PRO` | عملية أمنية | دورة أنشطة مترابطة ومتكررة ذات مدخلات ومخرجات | خطوات تفصيلية لحالة واحدة |
| `ART-PRC` | إجراء أمني | تسلسل خطوات قابل للتكرار داخل عملية | مهمة ذرية واحدة أو قيمة إعداد |
| `ART-PRG` | برنامج أمني | مبادرة مستمرة تضم حوكمة وموارد وعمليات متعددة | عملية واحدة أو خطة زمنية واحدة |
| `ART-PLN` | خطة أمنية | ترتيبًا مستقبليًا ذا نطاق ومراحل ومالكين ومواعيد | عملية دائمة أو مهمة منفردة |
| `ART-TSK` | مهمة | عملًا ذريًا محددًا له نتيجة إكمال واضحة | إجراءً متعدد الخطوات أو حالة تنفيذ مؤسسية |
| `ART-CFG` | إعداد تقني | قيمة أو حالة ضبط تقنية محددة قابلة للفحص | قاعدة منطقية لأداة أو ضابطًا عامًا |
| `ART-RUL` | قاعدة فنية | منطق كشف أو منع أو مطابقة تنفذه أداة | إعدادًا ثابتًا أو سياسة إدارية |
| `ART-EVD` | دليل | سجلًا أو تقريرًا أو مستندًا يثبت حدثًا أو حالة | طريقة التحقق أو المتطلب نفسه |
| `ART-MET` | مقياس/مؤشر | تعريف قيمة محسوبة بمدخلات وصيغة ودورية | تقرير نتائج أو هدفًا نوعيًا |
| `ART-EXC` | استثناء أمني | قرارًا مؤقتًا معتمدًا بعدم التطبيق، له مبرر وانتهاء | حالة `غير منطبق` أو قبول خطر بلا استثناء محدد |
| `ART-RSK` | خطر أمني | سيناريو عدم يقين له سبب وأثر واحتمال | عملية إدارة المخاطر أو تهديدًا مجردًا |
| `ART-AST` | أصل معلوماتي | شيئًا ذا قيمة يحتاج الحماية | نوع تقنية كسياق أو نطاق عام |
| `ART-THR` | تهديد | فاعلًا أو حدثًا أو قدرة قد تسبب ضررًا | ضعفًا قابلًا للاستغلال أو خطرًا كاملًا |
| `ART-VUL` | ثغرة | ضعفًا يمكن استغلاله | تهديدًا أو نتيجة فحص أو معالجة |
| `ART-OWN` | مالك/دور | دورًا مسؤولًا أو جهة مالكة قابلة لإعادة الاستخدام | اسم شخص أو إسنادًا خاصًا بملف مؤسسي |

## 3. خريطة المسميات العملية المقترحة

| المصطلح العملي | القرار الصحيح |
|---|---|
| حوكمة وتوجيه أمني | ليس نوعًا منفردًا. اختر `ART-PRI` أو `ART-OBJ` أو `ART-POL` أو `ART-PRG` أو `ART-PLN` أو `ART-OWN` أو `ART-REQ` حسب ماهية العنصر، واستخدم `ABS-GOV` وSD-01 للمستوى والمجال عند انطباقهما. |
| سياسة أمنية | `ART-POL`. |
| معيار أمني | `ART-STD`. |
| ضابط أمني | `ART-CTR`؛ واستخدم `ART-CTE` إذا كان العنصر تحسينًا لضابط محدد. |
| عملية أمنية | `ART-PRO`. |
| إجراء تشغيلي | `ART-PRC`. |
| تعليمات عمل | `ART-TSK` للمهمة الذرية، أو `ART-CFG` لقيمة ضبط، أو `ART-RUL` لمنطق أداة. إذا احتوت تعليمات متعددة الخطوات فهي `ART-PRC`. |
| مراقبة ورصد | قدرة الرصد `ART-CTR`، عملية المراقبة `ART-PRO`، خطواتها `ART-PRC`، قاعدة الكشف `ART-RUL`، السجل الناتج `ART-EVD`، ومؤشر التغطية `ART-MET`. |
| مراجعة | ممارسة مراجعة دورية تقلل الخطر `ART-CTR`، خطوات المراجعة `ART-PRC`، مهمة مراجعة مفردة `ART-TSK`، والنتيجة `ART-EVD`. |
| تقييم | عملية تقييم متكررة `ART-PRO`، منهجية التنفيذ `ART-PRC`، مهمة تقييم محددة `ART-TSK`، والتقرير `ART-EVD`. |
| اختبار وتحقق | إجراء الاختبار `ART-PRC`، تشغيل اختبار معين `ART-TSK`، قاعدة الاختبار التقنية `ART-RUL`، والنتيجة `ART-EVD`. لا يستخدم `ART-CTE` للاختبار. |
| إدارة مخاطر | العملية `ART-PRO`، الخطة `ART-PLN`، الخطر نفسه `ART-RSK`، وإجراء المعالجة المحدد `ART-TSK` أو ضابط `ART-CTR`. |
| امتثال ومتطلبات خارجية | الالتزام المستخرج `ART-REQ`. أما ISO أو PCI DSS ككل فهو `source_catalog` وتوثق الإحالات في `framework_mappings`. |
| توعية وتدريب | البرنامج `ART-PRG`، العملية `ART-PRO`، الإجراء `ART-PRC`، جلسة أو مهمة محددة `ART-TSK`، ومتطلب التدريب كوسيلة حماية قد يكون `ART-CTR`. |
| استثناء أمني | `ART-EXC`، مع الاعتماد والانتهاء. |
| سجل أو دليل إثبات | `ART-EVD`. |
| مؤشر قياس | `ART-MET`. |
| إجراء تصحيحي | في الكتالوج: `ART-TSK` لعمل محدد، أو `ART-PRC` لخطوات متكررة، أو `ART-CTR` لوسيلة حماية دائمة. المعالجة الخاصة بالمؤسسة تبقى في `remediation_actions` أو مهام الملف ولا تتحول إلى حقيقة مرجعية. |

## 4. شجرة القرار

طبّق الأسئلة التالية بالترتيب:

1. هل العنصر كيان خطر أو سياق بذاته؟ اختر من `ART-RSK`, `ART-AST`, `ART-THR`, `ART-VUL`, `ART-OWN`.
2. هل هو إثبات أو قياس أو استثناء؟ اختر `ART-EVD`, `ART-MET`, أو `ART-EXC`.
3. هل يصف ما يجب تحقيقه؟ اختر `ART-REQ`, `ART-OBJ`, أو `ART-PRI`.
4. هل هو توجيه أو حد مؤسسي؟ اختر `ART-POL` أو `ART-STD`.
5. هل هو وسيلة لتقليل خطر؟ اختر `ART-CTR` أو `ART-CTE`.
6. هل ينظم العمل؟ اختر `ART-PRG`, `ART-PLN`, `ART-PRO`, `ART-PRC`, أو `ART-TSK` حسب الحجم والزمن والتفصيل.
7. هل هو تنفيذ تقني دقيق؟ اختر `ART-CFG` للقيمة أو الحالة، و`ART-RUL` للمنطق التنفيذي.

إذا بقي نوعان محتملان، لا تستخدم قيمة «متعدد» في `type`. سجّل البديل المرفوض وسبب الترجيح، أو وجّه السجل إلى `AIR-HUMAN-REVIEW`.

## 5. الفرق بين العملية والإجراء والمهمة

| البعد | `ART-PRO` عملية | `ART-PRC` إجراء | `ART-TSK` مهمة |
|---|---|---|---|
| الغرض | إدارة قدرة مستمرة | وصف كيفية التنفيذ | إنجاز عمل محدد |
| البنية | أنشطة وأدوار ومدخلات ومخرجات | خطوات مرتبة وشروط وتفرعات | فعل واحد ونتيجة إكمال |
| الزمن | مستمرة أو دورية | يعاد استخدامها عند حدث | تنفيذ مفرد أو قابل للإسناد |
| المثال | إدارة دورة حياة الهوية | إجراء إنشاء وإلغاء الحساب | تعطيل حساب الموظف المغادر |

تعليمات العمل ليست كودًا جديدًا: مجموعة خطوات دقيقة هي `ART-PRC`، مهمة ذرية هي `ART-TSK`، قيمة تقنية هي `ART-CFG`، ومنطق أداة هو `ART-RUL`.

## 6. سلسلة MFA الصحيحة

النموذج ليس قائمة خطية إلزامية، بل رسم علاقات:

| العنصر | النوع | المثال |
|---|---|---|
| المبدأ | `ART-PRI` | أقل صلاحية ودفاع متعدد الطبقات |
| الهدف | `ART-OBJ` | حماية الحسابات عالية الصلاحية |
| المتطلب | `ART-REQ` | حماية الحسابات الإدارية بمصادقة قوية |
| السياسة | `ART-POL` | سياسة المصادقة للحسابات الحساسة |
| المعيار | `ART-STD` | الحد الأدنى المعتمد لعوامل المصادقة |
| الضابط | `ART-CTR` | فرض MFA للحسابات الإدارية |
| العملية | `ART-PRO` | إدارة الهوية والوصول |
| الإجراء | `ART-PRC` | تفعيل MFA ومراجعة الاستثناءات |
| الإعداد | `ART-CFG` | حالة إعداد MFA المطلوبة للمنصة |
| قاعدة الرصد | `ART-RUL` | تنبيه محاولة تجاوز العامل الثاني |
| مهمة الاختبار | `ART-TSK` | محاولة دخول اختبارية دون العامل الثاني |
| الدليل | `ART-EVD` | تقرير الحسابات وحالة MFA |
| المقياس | `ART-MET` | نسبة الحسابات الإدارية المحمية |
| الاستثناء | `ART-EXC` | استثناء مؤقت لنظام قديم |
| المعالجة | `ART-TSK` | معالجة الحسابات غير الملتزمة |

تستخدم العلاقات المنظمة بدل عبارة «البند المرتبط»: `REL-DER`, `REL-SAT`, `REL-SPL`, `REL-IMP`, `REL-VER`, `REL-MEA`, و`REL-MIT` حسب اتجاه العلاقة ومعناها.

## 7. الحقول المصاحبة لا تستبدل النوع

| مفهوم القائمة العملية | تمثيله في SecureGuide |
|---|---|
| نوع البند | `security_artifacts.type` بقيمة ART-* واحدة |
| المستوى الإداري | `abstraction_level` بقيمة ABS-* مستقلة |
| المجال الأمني | `primary_domain` و`sub_domain` وفق SDT |
| البند المرتبط | `artifact_relationships` |
| هدف البند | `objective_en` / `objective_ar` أو عنصر `ART-OBJ` مستقل عند الحاجة |
| نوع الإثبات | عنصر `ART-EVD` وعلاقة `REL-VER`؛ والأدلة الفعلية داخل الملف في `profile_evidence` |
| دورية المراجعة | `review_frequency` مرجعيًا، أو override خاص بالملف |
| المالك والمنفذ | `ART-OWN`/stakeholders مرجعيًا؛ والتكليف الفعلي خاص بالملف المؤسسي |
| التنفيذ والتحقق والفعالية والاستثناء | حقول منفصلة داخل `profile_artifacts`، لا داخل التصنيف المرجعي |
| مستوى النضج | قيمة مرجعية مضبوطة أو تقييم خاص بالملف، ولا يشتق من `type` |

## 8. بوابة القبول

قبل اعتماد النوع:

- يجب أن يكون واحدًا من أنواع USACM الـ22.
- يجب أن يجيب التبرير عن سؤال «ما هذا العنصر؟».
- لا يجوز استخدام المجال أو مستوى التجريد أو النشاط التشغيلي بدل النوع.
- العناصر المركبة التي تحتوي متطلبًا وضابطًا وإجراءً ودليلًا تقسّم إلى عناصر مترابطة.
- التصنيف المنخفض أو المتعدد احتماليًا يوجّه للمراجعة البشرية ولا ينشر تلقائيًا.
- تبقى حالة التنفيذ والمالك الفعلي والإجراءات التصحيحية الخاصة بالمؤسسة في طبقة الملف المؤسسي.

المرجع الآلي الموافق لهذه السياسة هو [`../reference/artifact_type_guidance_v1.json`](../reference/artifact_type_guidance_v1.json).
